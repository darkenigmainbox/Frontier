Every glyph below is the live icon at 14–16 px inside a fake IDE: activity bar, tabs, tree, toolbar, gutter and status bar. If an icon fails here, it fails in the product.

How to read the provenance badges

original — geometry invented for this set (cut-corner family, accent layer). Resemblance to any existing set would be coincidental.
conventional — the concept is common (magnifier, folder, pencil). Shapes are redrawn from scratch in the family language, but they will read familiar — that is intentional UX, not copying.
constrained — near-universal glyphs (scissors, padlock, play). Any honest redraw looks similar; the note on each icon says exactly which detail differentiates it.

Nothing here is traced, imported or path-copied from Lucide or any other library — every d attribute was authored by hand on the 24×24 grid.
