# Experimental — prototypes before they graduate

Runnable browser-first experiments. Each topic gets a folder; each folder
opens with something that runs without a build step.

- `Audio/` — procedural game-audio bank + editor for the racing ambience
  (wind, vegetation, surfaces, tyres, impacts). **Start here:
  `Audio/Audio.html`.** The bank is generated by `Audio/GenerateAudio.py`
  and ships under `Audio/Content/Audio/` so it can be copied verbatim into
  `Projects/Project-Zero/Content/Audio/` when it graduates.
